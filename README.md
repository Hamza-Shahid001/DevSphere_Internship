# DevSphere Internship

This repository holds the coursework and exercises from the DevSphere Internship. Each week's work lives in its own folder.

## Repository Structure

```
DevSphere_Internship/
├── Week_1/
│   ├── main.py      # Basic AI Logic System (rule-based recommendation chatbot)
│   └── README.md    # Details for the Week 1 project
└── README.md        # This file
```

## Weekly Projects

| Week | Folder | Topic | Summary |
|------|--------|-------|---------|
| 1 | [`Week_1/`](Week_1/) | AI Basics + Python | A console app with a movie recommender, activity recommender, weather advisor, and keyword chatbot, built on `if`/`else` rules and dictionary lookups. See [`Week_1/README.md`](Week_1/README.md). |

## Requirements

- Python 3.9 or newer
- No third-party packages are needed for the current projects

## Running a Project

Open a terminal in the week's folder and run its entry-point script. For Week 1:

```bash
cd Week_1
python main.py
```

On Windows you can also use `py main.py`.
